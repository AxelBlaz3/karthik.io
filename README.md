# karthikgaddam.dev

Personal portfolio website built with Next.js, Tailwind CSS, and shadcn/ui.

## Stack

- **Framework** — Next.js (App Router)
- **Styling** — Tailwind CSS + shadcn/ui
- **Font** — Geist & Geist Mono
- **Deployment** — TBD

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
